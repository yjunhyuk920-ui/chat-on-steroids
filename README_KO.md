# Chat On Steroids 한국어판

이 저장소는 [원본 Chat On Steroids](https://github.com/totec448-spec/chat-on-steroids)의 한국어 현지화 버전입니다. 앱의 기능과 보안 경계는 그대로 유지하면서 다음 화면을 한국어로 표시합니다.

- Electron 데스크톱 앱의 설정, 상태, 권한, 세션 관리 화면
- Chrome 확장 프로그램 팝업
- ChatGPT 입력창에 추가되는 압축·목표 진행 상태와 설정 메뉴

채팅 내용, 사용자가 작성한 목표, 인계문, 도구 실행 결과 및 저장된 세션 데이터는 번역하거나 변경하지 않습니다. 한국어 처리는 표시 계층에서만 수행됩니다.

## 주요 기능

Chat On Steroids는 ChatGPT 웹 화면과 로컬 PC를 MCP로 연결하는 데스크톱 앱입니다. 사용자가 허용한 폴더와 기능만 노출하며, Chrome 확장 프로그램이 채팅 세션 수집, 도구 호출 연결, 압축 후 이어하기, 실험적 다중 에이전트 기능을 보조합니다.

화면·마우스·키보드·클립보드 자동화는 Windows에서만 제공됩니다. 파일 및 명령 실행 권한은 데스크톱 앱에서 설정한 범위로 제한됩니다.

## 개발 환경에서 실행

필요 항목:

- Node.js 22 이상
- npm
- Chrome 또는 Chromium 기반 브라우저

```powershell
npm ci
npm run dev
```

## Chrome 확장 프로그램 설치

1. 데스크톱 앱을 실행합니다.
2. 앱의 설정 화면에서 확장 프로그램 폴더를 엽니다.
3. Chrome에서 `chrome://extensions`를 엽니다.
4. **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드합니다**를 눌러 `extension` 폴더를 선택합니다.
6. ChatGPT 탭을 새로고침하고 확장 프로그램 팝업에서 연결 상태를 확인합니다.

## 검증 및 빌드

```powershell
npm run verify

```

## 개인정보와 외부 전송

- 세션 이벤트는 로컬 데스크톱 앱에 저장됩니다.
- Goal 기능을 켜고 OpenRouter API 키를 설정한 경우에만 목표 판단을 위해 해당 서비스로 내용이 전송될 수 있습니다.
- 허용 폴더와 쓰기·명령·데스크톱 제어 권한은 앱에서 각각 설정합니다.
- 실제 사용 전에는 원본 저장소의 [보안 및 권한 설명](README.md#permissions-and-security-boundaries)을 함께 확인하세요.
